# CC-BY subclasses

Every document in this folder is our own original text, released under
**CC-BY-4.0** and built against **SRD 5.2.1**, which Wizards released under the
same licence.

**No OGL content is permitted here.** Not a sentence, not a feature name, not a
table of numbers from a 3.0/3.5 SRD source. Concepts may cross from
`../ogl/`; expression may not. The reasoning is in `../ogl/LICENSING.md` — OGL
1.0a §2 forbids applying "other terms or conditions" to Open Game Content, so a
single reused paragraph would drag the whole document out of CC-BY and into a
licence this folder does not carry.

Consequently nothing here carries the OGL, and nothing here carries a Section 15
chain. Adding one would falsely assert that we are distributing Open Game
Content.
