# Boot readiness diagnosis — unconditional bundled reconciliation

Read-only codex diagnosis, 2026-08-07, commissioned by the supervisor
after route-readiness timeouts recurred across four lanes (ADF, HA-8,
HA-10, DICE). This is a DIAGNOSIS, not a plan; no fix was written.
Ruling recorded as D225. `.claude/decisions.md` outranks this file.

Headline: every page load re-projects and re-verifies all 447 bundled
aggregates (339 of them spells) — roughly 2,373 child/root queries, 339
nested savepoints, at least three SHA-256 passes per spell, and spell
descriptions parsed FOUR times. Seeder guards skip the writes; they do
not skip the verification. CI contention amplifies this into 45-65s
timeouts, but a real user on a slow device pays it on every open.

1. **Boot path.** Browser capability probing gates startup for up to 1,276 ms. The database worker then asynchronously initializes SQLite/WASM and OPFS; after that, `lifecycle.open()` is synchronous: open connection → pragmas → validate 40 migration checksums → create/migrate schema → `quick_check`/foreign-key/schema validation → catalog migrations → seed. Only actual migration application is conditional; validation always runs.
