   through CI-7's previewReplacement/commitReplacement.

   archiving the whole set (D99) as ONE restorable unit.
4. Restore: ALL-OR-NOTHING for the set (D214). No partial restore, and no

   Pin the absence of partial restore, not just the presence of full
   restore.

   version, lineage rows, and attached characters — atomically (D214).
   This needs the ONE guarded exception to 0039's BEFORE DELETE
   permanence trigger. Scope that exception as narrowly as you can and
   pin that lineage remains immutable on every OTHER path: raw DELETE
   still refused, DELETE+INSERT rewrite still refused, UPDATE still
   refused. Those CI-7 pins must keep passing UNCHANGED — if one needs
   editing, that is a finding, report it rather than editing it.
