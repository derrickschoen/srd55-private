## Deliverable 1 — the half of D218 that is still unbuilt

BHC verified the FULL EXPORT half already satisfied and delivered a pin.
The SHARE LINK half was deliberately deferred to this unit, with the
measurements already taken:

- share links are currently reference-only (character-share.ts)
- budget: 131,072 encoded characters / 98,304 compressed bytes /
  524,288 decompressed bytes (sharing/schema.ts)
- `tryEncodeShareFragment` ALREADY returns a typed `too_large` result
  (sharing/codec.ts) — so the mechanism to detect non-fit exists

Build it: a share link ATTEMPTS to embed the non-SRD content its
character depends on; when the result does not fit the budget, the link
is still emitted WITHOUT the content and the user is WARNED AT EXPORT
TIME, naming what the recipient will need to import. Owner's words:
"make an effort to fit the content in if we can and [w]arn if we can't".

- A link that could not carry its content is still VALID under the
  install-then-open baseline. The warning is the contract, not a
  refusal.
- The recipient side must remain honest: opening a link whose content is
  absent already refuses with a message naming what to import — keep
  that, and make sure the two messages agree with each other.
- Wire format: if embedding requires a new wire version, that is a
  FROZEN-VECTOR event. Mint the new version alongside the old, never
  edit a frozen vector, and pin round-trips for BOTH.
- Pin all three cases: fits and embeds; does not fit, warns, and the
  recipient gets the honest refusal; SRD-only character produces an
  unchanged link with no warning.

## Lessons already paid for (the reviewer checks these first)
1. COMPILE GATE IS `npm run build`; holder objects for closure-assigned
   test callbacks.
2. A test must call what the ROUTE calls — three lanes shipped pins
   against convenient seams or hand-constructed objects.
3. When a visible label changes, grep the browser specs for the old
   exact string.
4. Exact-shape/key-set pins break when you add a field: grep and RUN
   them.
5. HA-10's catalog-layer completeness guard derives its own scan set —
   satisfy it; a new exemption needs a defended reason.
6. Strict-superset conversions must keep the DISCRIMINATING power, not
   just the facts. SRD-ONLY shipped a conversion whose replacement
   fixture could no longer distinguish the branch the test names.
7. Never regenerate an expectation from our own output. If a number
   moves, explain WHY before changing it.
