# .ai/ — read AGENTS.md

**The guidance for this directory is in [AGENTS.md](AGENTS.md). Read it.**

A pointer, not a copy — the same choice the repo root makes, for the same
reason. Guidance duplicated across two files drifts, and this directory exists
specifically to stop drift between a claim and its source. A second copy of the
rules here would be that failure committed by the library that forbids it.

The one thing worth repeating rather than linking, because it is what this
directory is FOR:

> **Never state a D&D rule, spell effect, class feature, or number from memory.**
> `grep -i '<keyword>' .ai/rules/INDEX.md` first. It costs one grep.
> Recall was wrong three times in one session on facts that were in `docs/srd/`,
> and another agent caught every one.

Everything else — the lookup protocol, the two-column `grep` trap, the drift
detector, how to add an entry — is in [AGENTS.md](AGENTS.md) and
[rules/MAINTENANCE.md](rules/MAINTENANCE.md).
