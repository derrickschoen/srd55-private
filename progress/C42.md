# C42 — character rules and source commands

Status: done (BUILD-PLAN increment 13)

## Delivered

- `update-character-rules.ts` persists the legacy toggle, refreshes all durable
  slot eligibility, and returns the prior toggle as its inverse.
- `update-source-config.ts` validates active ownership and the configurable
  source kind, updates standalone or nested Magic Initiate configuration,
  synchronizes parent configuration, handles Cleric/Druid Orders, regenerates
  stable slots/sources, and returns an integrity-signed snapshot inverse.
- `add-source.ts` validates definition identity, repeatability, total/class
  levels, Wizard acquisitions, Magic Initiate, nested origin-feat configuration,
  and Divine/Primal Orders. It atomically persists class levels/source roots and
  regenerates nested sources, slots, and spellbook entries.
- `remove-source.ts` restricts removal to owned active feat/species/background
  sources, atomically tombstones the root, recursively deactivates descendants,
  preserves orphan selections, and returns an integrity-signed snapshot inverse.
- Six integration tests assert persisted SQLite rows for rule refresh/inverse,
  nested configuration and rollback, stable Order orphan/reactivation, atomic
  class addition, nested source validation/repeatability, and recursive removal.
