## Self-critique

The audit caught three integration/parity risks and resolved them: typed command
interfaces now pass directly to the generic integrity API without needing an index
signature; canonical JSON has an explicit impossible-output guard; and verification
rejects uppercase signature text, matching PHP's lowercase `hash_hmac` plus exact
`hash_equals` behavior. No external agent was used, as required.
