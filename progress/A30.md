# A30 — spell access and route builder

Status: done (BUILD-PLAN increment 7)

## Delivered

- Added exclusive spell-slot assignment hydration for fixed grants, user
  selections, and empty slots, including positive-ID and dual-reference guards.
- Added the read-only spell-access builder for prepared, known, fixed, cantrip,
  slotted/free-cast, granted, and Wizard ritual-capability routes.
- Ported source-config and class/subclass definition ability resolution, total
  character-level proficiency, ability modifiers, attack bonuses, save DCs,
  deterministic route ordering, and complete route provenance.
- Added persisted-provenance route keys and stable first-route deduplication
  without collapsing distinct selection slots.
- Ordinary routes use live eligibility and active sources. `kept_override`
  bypasses both restrictions exactly as the oracle does, while active-version
  filters independently exclude stale-valid inactive slots and spellbook entries.
- Wizard ritual routes use active rules, the first matching active capability,
  ritual columns or tags, and the live spellbook; prepared, ordinary, and inactive
  entries do not gain ritual-only access.
