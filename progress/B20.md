# B20 — database and portable character backup

Status: done

## Delivered

- Added independently versioned complete-database and portable-character
  envelopes, strict product-facing validation errors, typed client methods, and
  four convention-discovered `backup.*` Worker handlers.
- Complete images preserve every SQLite table and use the frozen lifecycle's
  preflight integrity/schema/foreign-key checks, OPFS replacement, and recovery.
- Character documents preserve metadata, class levels, nested sources, slots,
  spellbook, preferences, overrides, acknowledgements, save points, and
  loadouts. Catalog IDs travel as stable content keys.
- Import creates a character atomically, remaps catalog/local IDs and source
  UUIDs, rewrites slot keys, and remaps nested `a7-v1` snapshots. Historical
  snapshot-only IDs are reserved so later restores cannot collide.
- Documented both formats, their RPC methods, portability rules, validation,
  atomicity, and the database-local history excluded from character documents.
